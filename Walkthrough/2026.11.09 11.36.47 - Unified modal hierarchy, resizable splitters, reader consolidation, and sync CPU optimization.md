# Unified modal hierarchy, resizable splitters, reader consolidation, and sync CPU optimization

## Context and observations

1. **Unified Modal Hierarchy**: `MessageMarkersModal`, `MessageMoveModal`, `MessageSnoozeModal`, and `ShortcutHelpModal` previously rendered ad-hoc `.mail-modal-backdrop` / `.mail-modal-card` overlays, while permanent message/folder deletion used browser `window.confirm()`. All modal and popover dialogs (`ConfirmDialogModal`, `MessageSaveModal`, `MessageMarkersModal`, `MessageMoveModal`, `MessageSnoozeModal`, `MessageSourceModal`, `ShortcutHelpModal`, `AccountWizard`, `FastMailModal`, `AccountNoteModal`, `AccountFolderModal`) now inherit `ModalBase` -> `CompactModal` (`380px`) / `DialogModal` (`480px`) / `WorkspaceModal` (`740px`) / `WideModal` (`1100px`) -> `CoreModal`, rendered in `AppModalHost` with opaque `AppColors.TooltipBackground`, click-outside dismissal, and `Escape` navigation.
2. **Column Splitters, Scrollbars & Fine-Tuning Settings**: `Settings` stores double-precision column widths (`MailCol1WidthPct` `20.0`, `MailCol2WidthPct` `32.0`, `MailCol3WidthPct` `48.0`) and `ScrollbarWidthPx` (`6`). Dragging `.mail-column-splitter` snaps within $\pm 3.0\%$ of the default ratio and moves freely outside that range. Scrollbars use a transparent track (`rgba(0,0,0,0)`) and flat `#4ADE80` thumb. `Settings.razor` exposes a **🎛️ Fine-tuning** section with default labels and per-setting Reset actions.
3. **Sidebar Layout, Expand/Collapse & Universal Drag-and-Drop**: `.mail-folder-hover-actions` remain hidden (`display: none`) until row hover so folder names retain horizontal width. Muted folder indicators (`🔕`) render in the left indentation gutter before the folder icon. `MailFolderData.IsExpanded` persists folder tree expansion, and `MailSidebar` supports drag-and-drop reordering/filing across account folders, accounts, mail folders, and messages, with `Escape` canceling active drags before release.
4. **Column Decoupling & Reader Consolidation**: Right-clicking inside Column 3 (`MailReaderPane`) operates strictly on the open reader message without mutating `MailUiState.SelectedMessages` or triggering `.mail-bulk-bar` in Column 2. The reader header consolidates `<BackButton>`, `.mail-reader-avatar`, and `.mail-reader-subject` on the top row, right-aligns `to ...` on the date row, sets `.mail-reader-frame` to `110%` minimum height with `overflow-y: hidden` and wheel forwarding, and merges actions into Read/Unread toggle, `↩️ Reply ▾`, `⭐ Labels`, `💾 Save` (native `GetSaveFileNameW` defaulting to `Downloads` + `explorer.exe /select`), `🗑️ Trash` / `Delete forever`, and middle/right-click toolbar pinning (`PinnedReaderActionsJson`).
5. **CPU & Storage Caching**: Removed the infinite 60fps `filter: hue-rotate` `aurora-drift` animation on `body::before`. `MessageStore.Folders` caches folder lists in memory per account, `MessageStore.Index` maintains an $O(1)$ per-sender count dictionary instead of scanning disk summaries on every `CountMessagesFromSender` call, and `SummaryPump` coalesces rapid arrival bursts (`90ms`) before firing UI notifications. Durable design rules are documented in [100 UI Element Principles & Proactive Extensions](../docs/UI-PRINCIPLES-100.md).
