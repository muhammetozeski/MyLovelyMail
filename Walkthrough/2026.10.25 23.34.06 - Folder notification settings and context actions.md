# Folder notification settings and context actions

The folder feature uses one UserData store for standard-role defaults and exact account/folder
overrides; see [the development contract](../docs/DEVELOPMENT.md#folder-notifications-and-unread-badges).
Mute is a notification deadline only. Badge preferences remain independent, Spam starts muted,
and Trash always suppresses notifications and unread badges. The sidebar context menu dispatches
existing operations through its owning Mail page and retains the clicked folder identity.

Rule destinations must be checked before a move can change a summary's message number. Both
receive protocols filter notification candidates at that point; POP3 ignores remote moves that
it cannot execute. No folder-mute flag is written to messages and no expiry timer was added.
