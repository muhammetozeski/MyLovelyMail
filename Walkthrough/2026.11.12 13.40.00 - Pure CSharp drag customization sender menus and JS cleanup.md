# Pure C# Drag Customization, Sender Context Menus, and JS Cleanup

## Context & Problem
Post-Argon changes left DOM-scraping JavaScript (`data-mouse4`/`data-mouse5` routing, JS sidebar drag helpers, JS context-menu positioning), bare CSS class literals in Razor markup, bubbling right-click handlers on sender elements, non-draggable folder-internal mail accounts, and static non-customizable toolbars/context menus.

## Architectural Decisions & Changes
1. **Mandatory-Only Browser JS Boundary**:
   - Stripped `mouse-buttons.js` down to WebView2 native context-menu suppression (`preventDefault`), Mouse 4/5 browser-back/forward prevention, and `<iframe srcdoc>` Mouse 4/5/contextmenu forwarding. Kept `mail-reader.js` strictly for `<iframe srcdoc>` scrollHeight measurement and wheel forwarding.
   - Removed all `data-mouse4*`/`data-mouse5*` attributes and bare `mail-*` CSS strings across `MainProject`; handled side-mouse actions in pure Blazor C# (`MouseActionService.HandleSideMouseUpAsync`).
2. **Sender Right-Click Context Menus (`SenderContextMenu`)**:
   - Wired `@oncontextmenu` with `@oncontextmenu:preventDefault="true"` and `@oncontextmenu:stopPropagation="true"` across Column 2 `SenderList` rows, Column 3 `Person` sheet, `MailList` `.mail-row-avatar`/`.mail-row-from`, and `MailReaderPane` sender/recipient/thread chips.
3. **Pure C# Sidebar & Account Reordering (`WorkspaceDragService`)**:
   - Replaced broken HTML5 WebView2 drag events with pure Blazor pointer tracking (`WorkspaceDragService`) for folder-internal `MailAccountData` rows, `AccountFolderData` groups, `MailFolderData` folders, `MailList` message filing, and `ListFilterWindow` filter ordering — persisted atomically in `account.json`, `account-folders.json`, `folder.json`, and `list-view.json`.
   - Made `DragEscapeBanner` `position: fixed` so active sidebar drags never shift sidebar item coordinates mid-drag.
4. **Universal Button & Context-Menu Drag Customization (`UiCustomizationStore` + `ActionDragService`)**:
   - Built `CustomizableActionBar`, `ActionSlot`, customizable `AppContextMenu`, and `UiCustomizerModal` (`WideModal`) across all 19 toolbar, hover-bar, and context-menu surfaces (`UserData/ui-layout.json`).
   - Non-fixed buttons reorder within their group, hide, or drag onto `📥 Right-Click` docks; context-menu and submenu items (including dynamic `Msg.AddTag:<Tag>` items) reorder, promote to 1-click root context menus, or drag directly onto screen toolbars.
5. **Diagnostics Hardening**:
   - Updated `DebugApi.cs` to fall back cleanly (`52539` -> `48539` -> `48540`, writing `AppCache/debug-api-port.txt`) when Windows WinNAT reserves port ranges, and updated `MainPage.xaml.cs` (`EnsureBackgroundRenderableWindow`) to check `!IsWindowVisible(hwnd)` so headless CDP input works when launched `--minimized`.
