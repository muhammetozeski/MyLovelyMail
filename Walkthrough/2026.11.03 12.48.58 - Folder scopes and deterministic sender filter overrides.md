# Folder scopes and deterministic sender filter overrides

The sidebar has both nested containers of accounts and mailbox folders. Filters now support both
through separate selectors; see [the filtering contract](../docs/FILTERING.md). Sender rules resolve
before account rules, mailbox rules, nearest account-container rules and application rules. Conflicting
actions resolve once per family, preventing multiple queued destinations. Explicit sender shortcuts
move before peers so an older conditional rule cannot silently shadow the clicked action.

Source inspection found that the old sound map keyed only by Message-ID could share a sound across
accounts or lose sound selection when the header was absent. Notification and sound decisions now
follow the actual arrival summary through a weak table. Corrupt filter reads retain the previous live
rules and block overwriting the unreadable file; retrying an edit reloads before applying its change.

`tests/FilterChecks` compiled the shared Razor/library source and passed 46 synthetic service checks,
including priorities, flags/tags, sender APIs, notification/sound isolation, read-only preview and failed
persistence recovery. All generated files/data stayed under `C:\C\TorAnonymity\FilterChecks` and no
provider was contacted. Build72 reported the existing UiCulture initializer warning and a ContactIndex
nullable warning in the independently owned contact area. Native interaction and provider behavior
remain distinct from these service checks.
