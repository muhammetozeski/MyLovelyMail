# Scoped senders, search clear button, mail sorting, and draggable advanced filter window

## Context & Requirements
- Scoped sender counts and sender list exclusively to the currently selected folder (`MailUiState.SelectedFolder.FullName`), preventing Trash/Spam aggregation.
- Added instant clear button (`✕`) to the search input (`CoreInput.razor` via `CoreInputCssClasses.Clear`).
- Implemented rich sorting for mails and senders (`ListViewState`, `MailSortField`, `SenderSortField`, `OpenSortMenu` context menu).
- Implemented floating draggable advanced filter window with pure C# pointer capture (`FloatingWindow.razor`, `ListFilterWindow.razor`, `ListFilterService`), conflict resolution (override precedence on conflicting boundaries), and manual reordering via up/down arrow buttons (`▲` / `▼`).
