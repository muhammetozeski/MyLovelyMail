# Listed conversation selection and quick action ownership

Source inspection found that existing right-click commands were available without visible reader or
workspace equivalents, and mixed selections offered only star/importance toggles. The mail page now
shares new selection/navigation/explicit-flag factories in `Mail.razor.QuickActions.cs`; visible buttons
open the existing shared menu host. [Quick action contracts](../docs/QUICK-ACTIONS.md) explain selection
overlap, partial inversion and captured-identity behavior.

Navigation steps displayed rows while conversation-internal navigation retains its own N/P behavior.
Keyboard focus now resolves conversation members to their displayed row, and modifier guards prevent
browser shortcuts from triggering ordinary triage. These are source-reviewed changes; the parent task
owns compilation, Windows publishing and user review. The implementation does not change reader
sandbox or external-content policies.
