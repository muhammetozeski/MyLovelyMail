# 2026.11.25 16.57.00 - UI, sync speed, folder persistence, and warning root-cause overhaul

## Context
Users reported sluggish/repeated syncing, broken folder ordering, cluttered multi-row toolbars, misplaced popovers, raw action IDs in the UI customizer, dark-theme contrast breaks, and repeated `⚠️` sync warnings on accounts.

## Key observations & decisions
- **IMAP timeout root cause (verified in live `AppCache/Logs`):** `ImapSyncService.SyncAccountAsync` wrapped connect + folder list + INBOX + 2 large background folders inside one 30s Polly `AttemptTimeout`, while `SummaryItems` requested `MessageSummaryItems.PreviewText` on Gmail (no RFC 8970 `PREVIEW`, forcing per-message partial body fetches) and `RefreshStalestFoldersAsync` sorted by `TotalCount != CountSummaries` (permanently pinning >300-message folders). Fixed by gating `PreviewText` on `ImapCapabilities.Preview`, guarding each IMAP step with `ResiliencePolicy.GuardStep`, filtering `FolderSyncPolicy.PullsFromServer` before taking stalest folders, sorting by `LastSyncedUtc`, and adding `LIST-STATUS` + `UIDNEXT` zero-fetch skips + parallel direct/Tor sync pools.
- **Mail.tm 429 & false `⚠️` badges (verified in live logs + source):** Added shared `api.mail.tm` request pacing (`380ms`) and up to 3 `Retry-After` waits; stopped transient `ImapIdleService` socket drops, pure remote-server slowness timeouts, and confirmed offline-internet outages from incrementing `ConsecutiveFailures` (they still log and surface via `SyncHealth.LastNoticeMessage` in tooltips/Logs, while real auth/config/protocol errors still raise `⚠️`).
- **Folder layout & UI organization (verified via `DebugApi` dark-theme screenshots):** Persisted folder order/collapse state in `UserData/folder-layout.json` (`FolderLayoutStore`); replaced `SidebarTop` clutter with a circular glowing green `+` orb (`GlowPlusButton`, 85% of bar height, clockwise lerp-out spin before opening `Create new`, moving `Sync` inside it since `SyncHeart` triggers sync); consolidated `ListToolbar` onto a single row; added section dividers & viewport `clamp()` to context menus; replaced Compose `From:` chips with an account-color-tinted dropdown; split Settings into 6 category tabs; fixed `UiCustomizerModal` fallback labels via static `UiActionCatalog` and widened `WideModal`; fixed dark-theme surfaces (`Tor -> Bridges`, `Signature` preview, `<CoreToggle>` in `FilterRules`, focus outlines, toast overlap).
- **Duplicate `Önemli` / `önemli` investigation (verified in live `folder.json`):** `[Gmail]/Önemli` (`UidValidity=9`, 597 msgs) is Gmail's built-in `\Important` folder while `önemli` (`UidValidity=12`, 0 msgs) is an empty custom IMAP label returned directly by Gmail's server (not created by MyLovelyMail). Removed the temporary `(Gmail)` label suffix and exposed `folder.FullName` in the folder tooltip instead.

## Outcome
Verified visually in `Playful Starlight` dark theme via `DebugApi` side-by-side comparisons and regression checks (`FilterChecks` + `MyLovelyMail.Web` + Windows build). See [docs/LESSONS.md](../docs/LESSONS.md) for durable rules.
