# Shared Windows and Android application entering maintenance cleanup

MyLovelyMail uses one MAUI head and a shared Razor library for Windows and Android. The existing Android release is v1.40.0. Current work is code and folder cleanup while preserving user-visible behavior and the Css.razor theme system. The user will not connect a phone for testing.

The project already had protocol, storage and rendering lessons, but no documentation entry point or handover guide. The new index links to those existing sources; it does not replace their evidence. The initial local files were committed before cleanup.
