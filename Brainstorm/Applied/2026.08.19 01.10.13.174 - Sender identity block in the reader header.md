# Sender identity block in the reader header

Kategori: pastel-identity | Efor: S | Rank: 1

## Ne
Reader header (Mail.razor 327-340) shows the sender as flat text while every list row carries a pastel gradient avatar. Two parts, both RAM-only, no network, no storage:

(1) Avatar: render a 44px gradient circle before `.mail-reader-titles` inside `.mail-reader-header` (already `display:flex; align-items:flex-start; gap:12px`, MailCss.razor:570), calling the EXISTING `AvatarGradient(open)` / `AvatarInitials(open)` directly. Do NOT create `Services/SenderIdentity.cs` — `Mail.razor.Interaction.cs` is `public partial class Mail`, the same class Mail.razor compiles into, which is why Mail.razor:205 already calls `@AvatarGradient(message)` from markup. Both helpers take `MailMessageSummary` and `open` is one, so no signature change. Add one `.mail-reader-avatar` rule in MailCss.razor beside the existing `.mail-row-avatar` (line 438), using `AppMeasures.Size` + `AppStyles.ShadowSoft`.

(2) History pill under `.mail-reader-meta`: a private static that scans `MessageStore.GetFolders(accountId)` + `GetSummaries(...)` (a RAM ConcurrentDictionary index) for `FromAddress` matches, returning count, oldest `DateUtc` and unread count. Render as a soft pill — "💌 8 from this sender · since 12 Mar" — that on click calls `RunSavedSearch($"from:{open.FromAddress}")`. Verified to work end to end: `SearchService.ParseQuery` has a `from:` predicate (SearchService.cs:61) matching `$"{s.FromName} {s.FromAddress}"`, and `RunSavedSearch` (Mail.razor.cs:206) sets `SearchAllFolders = true` before refreshing.

One constraint the proposal missed: the scan is O(all summaries in the account) and the reader re-renders on every `HandleStateChanged`. Compute it once when the open message changes — cache it in a field keyed by `open.Uid`, filled where the reader already reacts to a message switch — not per render.

## Neden
The pastel gradient is the app's sender identity and it currently vanishes at the moment the user is looking hardest at one sender. Carrying the same circle into the reader makes the identity continuous instead of a list decoration. The pill answers "do I know this person?" from an index already in RAM and turns it into a one-click cross-folder filter that the search parser already supports.
