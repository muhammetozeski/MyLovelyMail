# Remember window bounds across restarts

Kategori: window-polish | Efor: M | Rank: 40

## Ne
Add Setting<int> WindowX/WindowY/WindowWidth/WindowHeight and Setting<bool> WindowMaximized to Settings.cs (new 'Window and startup' entries). In App.CreateWindow (MyLovelyMail/App.xaml.cs) apply the saved bounds to the MAUI Window before returning it, clamping to the current virtual-screen area so an unplugged monitor cannot leave the window off-screen; treat width/height 0 as first run and keep defaults. Persist on change by hooking window.SizeChanged/Destroying inside TrayService.AttachWindow, which already receives the Window, debouncing writes through the existing Setting<T> engine.

## Neden
The app currently opens at the default MAUI size and position every launch; users of a mail client keep it open all day and expect their layout back. Uses only the settings engine and window hooks that already exist.
