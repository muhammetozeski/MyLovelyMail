# Stable deploy root so UserData survives version updates

Kategori: resilience | Efor: M | Rank: 1

## Ne
Today every export creates vNNN as its OWN root, so UserData/UserCache start empty after each update - accounts and mail vanish from the user's perspective. Restructure Export.ps1: the deploy root holds the launcher and ONE stable AppData (updated in place when the app is closed; versioned archive copies optional), so AppPaths resolves the SAME root every time and UserData persists across updates. Include a one-time migration: if the stable root has no UserData but an older vNNN sibling does, copy it forward on first run.

## Neden
The user's real installation lost its accounts when moving v006 to v007 during testing; user data must survive updates by design.
