# Keyboard triage shortcuts for the message list

Kategori: productivity | Efor: S | Rank: 20

## Ne
Give the message list a @onkeydown handler (tabindex=0 on the list container in Mail.razor, no JS interop beyond focus). Keys: J/K or arrows move a highlighted row (new MailUiState.FocusedMessage), Enter opens it in the reader, U toggles read/unread, S toggles Flagged, Delete deletes, Escape closes the reader (MailUiState.CloseMessage). Highlight style uses AppColors accent tokens in MailCss.razor. A '?' key opens a small GlassCard overlay listing the shortcuts.

## Neden
Keyboard-only triage is what makes power users fast, and Blazor's built-in KeyboardEventArgs means this needs zero external JS — just a focused container, a FocusedMessage field on the existing MailUiState, and flag mutations through MessageStore that already exist.
