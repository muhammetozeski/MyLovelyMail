# Per-account settings page with override toggles

Kategori: ux | Efor: L | Rank: 2

## Ne
AccountSettingsPage.razor (route /Settings/Account/{AccountId}): renders every InheritedSetting of AccountSettings as a row showing the effective value, an Overridden badge, an editor control (toggle/number/text by type) and a reset-to-inherited button; saving calls AccountSettings.Save which persists only overridden keys. Reached from the Accounts list in Settings. Also editable: display name, color swatch row, enabled toggle (MailAccountData via AccountStore.Save).

## Neden
The inheritance engine is the user's core requirement but has no UI yet; children must follow globals until overridden, visibly.
