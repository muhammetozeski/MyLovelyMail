# Mail domain models and disk-backed store

Kategori: resilience | Efor: L | Rank: 3

## Ne
MailAccountData, MailFolderData, MailMessageSummary (RAM index: id, subject, from, date, flags, size, folder), full MIME stored on disk under UserCache/Accounts/<id>/Messages. MessageStore keeps only summaries in RAM (ConcurrentDictionary), loads full body from disk on open. Index file per folder as JSON lines.

## Neden
User rule: never hold all mails in RAM, only mapping; deleting UserCache must be safe (re-sync from server).
