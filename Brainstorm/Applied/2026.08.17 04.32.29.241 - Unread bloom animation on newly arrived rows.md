# Unread bloom animation on newly arrived rows

Kategori: delight | Efor: M | Rank: 40

## Ne
Track which UIDs are new since the last render: in Mail.razor.cs, subscribe to MessageStore.OnFolderChanged (already an Action<string,string> of account/folder) and diff the folder's summaries against a HashSet<string> of previously seen message keys; freshly arrived unread messages get an extra CSS class mail-row--bloom on their button in Mail.razor (line ~108, next to the existing mail-row--unread class). In MailCss.razor add a pure-CSS keyframe: the row starts slightly scaled down with a soft pink radial glow behind the unread dot, blooms to full size over ~600ms with a petal-like box-shadow pulse using the theme accent token. Remove the key from the new-set after first render so the animation plays once. Zero JS, works with the existing per-account accent tinting.

## Neden
New mail currently just appears in the list with no visual event; a one-shot bloom makes the moment of arrival feel alive and matches the LovelyBloom theme identity, using only state MessageStore already broadcasts.
