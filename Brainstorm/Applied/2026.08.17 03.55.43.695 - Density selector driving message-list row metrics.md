# Density selector driving message-list row metrics

Kategori: deeper-settings | Efor: S | Rank: 30

## Ne
Settings.MessageListDensity (Cozy/Comfortable/Compact) is persisted but unused. Add a three-option segmented control to the Appearance section of Settings.razor, and make MailCss.razor emit row padding, font-size and preview-line-count values from the current density (Cozy: roomy rows + 2 preview lines, Comfortable: current look, Compact: tight single-line rows, no preview). Subscribe Mail.razor.cs to Setting.OnChanged so the list reflows immediately without restart.

## Neden
Instant, visible payoff from an already-declared setting; Compact mode matters for heavy triage users and the CSS-from-C# theme pipeline (*Css.razor) is exactly built for this kind of token variation.
