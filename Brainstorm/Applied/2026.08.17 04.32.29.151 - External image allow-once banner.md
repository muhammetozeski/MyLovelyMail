# External image allow-once banner

Kategori: reading | Efor: S | Rank: 40

## Ne
Change MailBodyRenderer.Render to return a small RenderResult (Html + bool RemoteImagesBlocked + int BlockedCount) instead of string, set when RemoteImageSources() actually replaced anything, and add an allowRemoteImages parameter that skips the blocking step. Mail.razor.cs keeps a per-session HashSet of (accountId, folder, uid) allowances; when the open message had images stripped, the reader pane shows a slim banner above the iframe: 'N external images blocked - Show once'. Clicking adds the key to the set and re-renders with images allowed; switching messages or restarting drops the allowance. Banner styled in MailCss.razor with the existing pastel warning tint.

## Neden
ExternalImagesPolicy.Block is the default, so most HTML mail currently renders with silent 1x1 placeholders and the user has no way to see images short of changing the global setting. Allow-once is the standard privacy-preserving UX and needs no persistence.
