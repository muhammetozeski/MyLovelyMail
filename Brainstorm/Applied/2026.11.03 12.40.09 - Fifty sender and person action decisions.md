# Fifty sender and person action decisions

The first twenty ideas form the requested useful sender-action set. Implemented means wired to
the existing application operation or a dedicated sender workflow; runtime verification is tracked
separately. Related choices share submenus rather than filling the first menu level.

| # | Idea | Decision |

| 5 | File future sender mail without moving existing history | Implemented; same-account destination submenu |
