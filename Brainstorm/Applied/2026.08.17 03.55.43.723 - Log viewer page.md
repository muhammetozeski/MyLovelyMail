# Log viewer page

Kategori: data management | Efor: S | Rank: 30

## Ne
A Logs.razor page (plus LogsCss.razor for styling) that renders the existing in-memory Logger.AllLogs / AllLogsUserFriendly queues: newest-first list, text filter box, level filter (parse the level token Logger already writes per line), auto-refresh toggle on a short timer, and buttons wired to the existing Logger.GetAllLogsText (copy to clipboard) and Logger.ClearAllLogs. If Logger.WriteToDisk is on, also list the Logs folder files with open-in-explorer. Reachable from the settings page or tray menu.

## Neden
Logger already buffers everything in RAM with copy/clear helpers built for exactly this ('copy logs' DevTools use-case in Logger.cs) — the only missing piece is a page to look at them, which turns bug reports from 'attach a debugger' into 'open Logs and copy'.
