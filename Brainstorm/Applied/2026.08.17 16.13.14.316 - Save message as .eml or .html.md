# Save message as .eml or .html

Kategori: reader depth | Efor: M | Rank: 60

## Ne
New static MessageExportService in MainProject/Services/Mail/MessageExportService.cs with two methods: ExportEml(account, folderFullName, summary, targetPath) writes the raw bytes from MessageStore.TryLoadFullMessage straight to disk; ExportHtml(...) reuses MailBodyRenderer.Render (allowRemoteImages true for a self-contained snapshot) and prepends a simple header block (From/To/Date/Subject) before saving. Wire two IconButton entries into the reader toolbar in MainProject/UI/Pages/Mail.razor next to the existing reply buttons, using the Windows save-file picker for the target path. The .html file doubles as the print path: open it in the default browser and Ctrl+P.

## Neden
Users lose access to mail when an account dies; the raw MIME is already sitting on disk via MessageStore, so .eml export is nearly free, and .html export gives archiving plus printing in one feature with zero new rendering code.
