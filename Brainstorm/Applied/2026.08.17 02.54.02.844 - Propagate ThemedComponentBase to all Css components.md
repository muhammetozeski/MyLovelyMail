# Propagate ThemedComponentBase to all Css components

Kategori: ux | Efor: S | Rank: 3

## Ne
Add '@inherits ThemedComponentBase' to the remaining parameterless *Css.razor components (CoreButtonCss, CoreCardCss, CoreChipCss, CoreInputCss, CoreModalCss, InfoPopoverCss, StackCss, PageBaseCss, LoadablePageCss) so a theme swap re-renders every emitted style block, not only the four already patched.

## Neden
Without it, glass cards/buttons keep the previous theme's colors after switching themes until the page reloads.
