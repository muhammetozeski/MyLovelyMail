# Pastel gradient sender avatars with initials

Kategori: message list flash | Efor: M | Rank: 50

## Ne
In Mail.razor's .mail-rows loop, add a <span class="mail-row-avatar"> before .mail-row-main showing 1-2 initials derived from message.FromName (fallback FromAddress). Pick the gradient deterministically: stable hash of FromAddress modulo AppColors.MonthGradients.Length, so each sender always gets the same pastel gradient pair; render it as an inline linear-gradient background. Style in MailCss.razor: circular (AppMeasures.Radius.Circular), ~32px (respect MessageListDensity - shrink to ~24px for compact), TextOnFilledSurface color, Weight.Heavy, flex-shrink 0. Helper method GetAvatarGradient(string address) lives in Mail.razor code block. Keep the existing mail-row-dot unread indicator, or move it to a small ring around the avatar for unread rows (border: 2px var(--account-accent)).

## Neden
Biggest single visual upgrade to the list: turns a text-only column into a colorful, scannable one, exactly the 'cafcafli' direction requested, and reuses the existing MonthGradients theme asset with zero new dependencies.
