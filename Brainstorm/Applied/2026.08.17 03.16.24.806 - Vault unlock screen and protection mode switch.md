# Vault unlock screen and protection mode switch

Kategori: vault UX | Efor: M | Rank: 20

## Ne
A VaultUnlock.razor page (with VaultUnlockCss.razor, themed via AppColors/AppMeasures) shown at startup when CredentialVault is in AES-GCM master-password mode and not yet unlocked: pastel glass card, password CoreInput, unlock button, shake-and-message on wrong password, retry counter. Routes.razor gates navigation to Mail until CredentialVault reports unlocked. In Settings.razor add a 'Vault protection' section: shows current mode (DPAPI vs master password) and a switch flow - entering a new master password re-encrypts the vault from DPAPI to AES-GCM, or entering the current master password converts back to DPAPI, both by decrypting all entries and re-saving through the existing CredentialVault export/import primitives. Also a 'Lock now' button that clears the in-memory key and returns to the unlock screen.

## Neden
CredentialVault already supports both protection modes and portable export, but there is no UI to unlock, switch modes, or lock - the capability exists headless. This closes the gap with pure UI plus calls into existing vault code, and gives the master-password mode an actual usable entry point.
