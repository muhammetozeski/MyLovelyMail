# Sync status heart pulse indicator

Kategori: lovely design delight | Efor: S | Rank: 30

## Ne
A small CSS-drawn heart (two border-radius pseudo-elements, no SVG asset) in the folder-pane footer or toolbar that beats while syncing and rests with a faint glow when idle. SyncScheduler already exposes IsSyncing and OnSyncStateChanged — a tiny SyncHeart.razor component (ThemedComponentBase) subscribes, toggles a 'beating' class driving a heartbeat @keyframes (double-thump scale 1 → 1.15 → 1 → 1.1), and on sync completion plays a brief 'settle' shimmer. Tooltip shows last sync time. Colors from AppColors so it follows LovelyBloom and dark themes automatically.

## Neden
Replaces an invisible background process with an on-brand living signal; the event hook already exists, so this is one component plus one Css component.
