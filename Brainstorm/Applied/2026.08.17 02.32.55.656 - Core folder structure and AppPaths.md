# Core folder structure and AppPaths

Kategori: resilience | Efor: M | Rank: 0

## Ne
Create static AppPaths class in MainProject: resolves MyLovelyMail root (launcher dir), AppData (MAUI files), UserData, UserCache, AppCache subfolders. App creates all folders itself at startup in MauiProgram. All disk IO in the app goes through AppPaths.

## Neden
User-mandated output layout; every later feature (settings, mail store, cache) depends on these paths existing.
