# The signature is an HTML document, not a line of plain text

Kategori: feature | Efor: L | Rank: 12

## Ne
İmza bugün düz metin ve gövdeye düz metin olarak ekleniyor:

    const string SignatureDelimiter = "\n\n-- \n";

    static string SignatureBlock(MailAccountData account)
    {
        string signature = AccountStore.GetSettings(account.Id).Signature.Value;
        return signature.Length == 0 ? string.Empty : SignatureDelimiter + signature;
    }

Ayar sayfasındaki kutu da düz bir `<textarea>`. Kullanıcı oraya HTML, CSS ve JavaScript
yazabilmek istiyor — "normal bir html alıcısı işte".

Yapılacak:
1. İmza alanı bir HTML belgesi kabul etsin. Kutu, kod yazmaya uygun olsun (tek aralıklı yazı
   tipi, satır numarası, tab desteği, sekmeyle girinti).
2. Kutunun yanında **canlı önizleme**: sandbox'lı bir iframe içinde imza olduğu gibi render
   edilsin. Önizlemede CSS ve JavaScript çalışsın — kullanıcı ne yazdıysa onu görsün.
3. Mail gönderimi HTML'e geçsin: mesaj `multipart/alternative` olarak kurulsun. `text/plain`
   parçası gövdenin düz hâli + imzanın metne indirgenmiş hâli; `text/html` parçası gövdenin
   HTML'e çevrilmiş hâli + imzanın kendisi. Gönderilen HTML parçasında script etiketleri ve
   olay öznitelikleri temizlenir (alıcı istemcileri zaten çalıştırmaz, ama temizlenmemiş bir
   script maili spam'e düşürür); CSS ve yapı olduğu gibi gider.
4. İmzadaki `cid:` ve `data:` görseller gönderime dahil edilsin.
5. Yanıt/ilet yollarında imza yine alıntının üstünde dursun; `StripSignature` HTML imzayı da
   tanısın (hesap değişince eskisi temizlenip yenisi konur).
6. Geçiş: bugünkü düz metin imzalar kaybolmasın — ilk açılışta HTML'e çevrilir (satır sonları
   `<br>`, metin kaçışlı).

## Neden
Ayarın adı `Signature` ve kullanıcı ondan bir imza bekliyor: logo, renk, bağlantı, düzen.
Projede daha önce çıkan ders şuydu — "tanımlanmış ama karşılığı olmayan ayar, kullanıcıya
verilmiş boş sözdür"; `SignatureHtml` adı zaten bir kez bu yüzden değiştirilmişti. Şimdi
istenen tam olarak o karşılığın verilmesi. WebAssembly ise ayrı ve büyük bir iş; bu görevin
kapsamında değil, gerekirse kendi görevi açılır.
