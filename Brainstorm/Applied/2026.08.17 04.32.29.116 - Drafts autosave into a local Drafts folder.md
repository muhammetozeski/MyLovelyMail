# Drafts autosave into a local Drafts folder

Kategori: compose | Efor: M | Rank: 40

## Ne
Add ComposeService.SaveDraftAsync(ComposeDraft): serialize the draft to a MimeMessage (Draft flag) and store it via MessageStore.SaveFullMessage + UpsertSummaries into a local 'Local/Drafts' folder (same pattern as ArchiveToSentAsync's local Sent path, FolderRole.Drafts, IsLocal=true, Fnv1aHash uid keyed on a stable per-draft Guid so re-saves overwrite the same uid). In Mail.razor.cs, debounce-save on compose field edits (System.Timers.Timer, ~3s idle) and save on compose close; delete the draft summary+MIME after successful SendAsync. Opening a message in the Drafts folder reopens it in the compose pane via MailUiState.OpenCompose with fields parsed back from the stored MimeMessage.

## Neden
A crash or accidental close currently loses everything typed in the compose pane; drafts are a baseline mail-client expectation and the local-folder plumbing already exists in MessageStore, so this is mostly reuse.
