# Folder and filter actions: 50 reviewed ideas

Reference patterns: [Outlook rule ordering and Stop](https://support.microsoft.com/en-us/outlook/mail/stop-processing-more-rules-in-outlook)
and [Gmail filters created from a message](https://support.google.com/mail/answer/6579).
Project-specific choices follow [the filtering contract](../../docs/FILTERING.md), rather than copying
provider behavior. Added means implemented in the scoped rule engine/editor; Integrated identifies
shared menu/sender wiring owned by the corresponding work area. Existing features were retained.
