# Message-ID of a Tor-only account carries the Windows computer name

Kategori: protection | Efor: S | Rank: 2

## Ne
ComposeService uses new MimeMessage() as-is and never sets MessageId, so MimeKit generates one
from the machine host name (verified: the domain part equals both Dns.GetHostName() and
Environment.MachineName).
Fix: set MessageId explicitly for a Tor-only account, using the account own mail domain, e.g.
MimeUtils.GenerateMessageId(domainOfTheAccountAddress).

## Neden
The recipient, every relay and the provider Sent folder see <...@COMPUTERNAME> - a stable machine
identifier tying this mailbox to every other mail the machine ever sent, over Tor or not. The
transport is anonymous and the content is not.
