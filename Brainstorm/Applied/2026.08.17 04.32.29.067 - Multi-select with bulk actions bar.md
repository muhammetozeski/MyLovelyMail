# Multi-select with bulk actions bar

Kategori: triage | Efor: M | Rank: 40

## Ne
Add a static SelectionState (or extend MailUiState) holding HashSet<uint> SelectedUids plus OnSelectionChanged. In Mail.razor message list: hover/always-visible checkbox per row, Ctrl+Click and Shift+Click range select, Ctrl+A select-all in folder. When SelectedUids.Count > 0, slide in a glassy bulk bar above the list with buttons: mark read/unread, star, important, tag picker, delete — each just loops MessageActions.MarkRead/ToggleFlagged/ToggleTag/Delete over the selection, then clears it. Esc clears selection; the existing J/K keyboard triage keeps working on the focused row.

## Neden
Single-message triage is shipped but cleaning 40 newsletters still takes 40 clicks; bulk ops are the biggest remaining friction and reuse MessageActions verbatim with zero new server code.
