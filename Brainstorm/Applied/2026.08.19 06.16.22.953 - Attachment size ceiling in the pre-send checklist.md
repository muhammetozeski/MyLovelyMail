# Attachment size ceiling in the pre-send checklist

Kategori: Files in and out | Efor: S | Rank: 1

## Ne
Add a sixth check to SendGuardService.Inspect: sum new FileInfo(p).Length over draft.AttachmentPaths.Where(File.Exists), inflate by the base64 factor (~1.37x, since the ceiling a server enforces is the encoded size), and emit a SendWarning with a new AttachmentSizeCode = "attachment-too-large" when it passes the account's ceiling. The ceiling is a new Setting<int> MaxAttachmentTotalMb in Stores/Settings.cs (0 = off) mirrored as an InheritedSetting<int> in Stores/AccountSettings.cs right beside OfflineMaxCacheMb, so per-account inheritance comes for free. The warning text names both numbers ("24.8 MB of attachments, over this account's 20 MB limit") rather than a bare refusal. Widen DebugApi's GET /send-check to read query.GetValues("attachment") instead of the single attachment param, so a multi-file draft is testable.

## Neden
This is the missing half of the too-large-to-send story. The checklist stops for a missing attachment but never looks at what the present ones weigh: ComposeService.SendAsync hands every staged file to BodyBuilder and lets the server decide. How that failure surfaces depends on the server. A 552 comes back as SmtpCommandException, which IsConnectionFailure does not match, so it throws and the user at least sees an error. A server that instead drops the connection mid-DATA lands in the IOException/SocketException branch, gets parked in the local Outbox with the draft deleted, and the periodic flush retries the same too-big message with nothing explaining why. Both paths are worse than one sentence before the send, and the second one is silent. The ceiling is a number the user sets rather than one discovered from the server, which keeps the whole check a pure function of the draft, exactly like the five checks already there. Verification is entirely offline through the DebugApi: write two temp files of known size, GET /send-check with both attachment params, assert the code appears and disappears as the ceiling moves.
