# Every wizard probe shares one circuit isolation key

Kategori: protection | Efor: S | Rank: 4

## Ne
ConnectTriageService passes the literal "probe" as the isolation key, so every account probe gets
the same SOCKS username and password.
Fix: use the account id, falling back to the host being probed when there is no account.

## Neden
On a system daemon or a Tor Browser - neither of which gets the IsolateDestAddr flag the
app-managed tor is started with - probes for two different Tor-only mailboxes can share a circuit,
letting one exit see both servers from one client. Connect-only and wizard-only, so small, but it
is free to fix.
