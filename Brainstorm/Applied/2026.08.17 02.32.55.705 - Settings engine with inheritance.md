# Settings engine with inheritance

Kategori: resilience | Efor: L | Rank: 1

## Ne
Port Setting<T>/ISetting/ISettingSetup/SettingsManager pattern from VirusTotalScanner into MainProject/Stores. Extend with InheritedSetting<T>: per-account child settings reference a parent Setting<T>; child tracks IsOverridden flag; if not overridden, reads flow to parent live. Persist global config to UserData/config.txt, per-account to UserData/Accounts/<id>/account.txt.

## Neden
User explicitly required inheritance-with-override-tracking semantics that primitive fields cannot express.
