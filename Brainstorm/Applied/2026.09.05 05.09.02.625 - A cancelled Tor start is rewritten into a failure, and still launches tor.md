# A cancelled Tor start is rewritten into a failure, and still launches tor

Kategori: resilience | Efor: S | Rank: 4

## Ne
TorService.StartOwnTorAsync catch (Exception) also catches the caller OperationCanceledException
and rethrows it as TorUnavailableException("Tor could not be started: The operation was
canceled."), writing that into LastError. Separately TorProcess.StartAsync checks the token
nowhere before process.Start().
Fix: let OperationCanceledException through untouched, and check the token before starting a
process.

## Neden
An IDLE loop cancelled by Refresh() while a bootstrap is being awaited marks the account as
failing and rotates its circuit before the delay finally observes the token. And a discovery pass
whose cancellation was swallowed by VerifyAsync starts a tor process on behalf of an operation
that was already cancelled, then throws.
