# Filter rules editor page

Kategori: ux | Efor: L | Rank: 1

## Ne
FilterRules.razor page (route /Settings/Filters, linked from Settings): list rules from FilterRuleStore with enable CoreToggle, up/down reorder, delete; an editor form (add or edit) with name, account picker (All or specific), match mode segmented control, dynamic condition rows (field/operator/value selects + inputs) and dynamic action rows (type select + argument input with per-type placeholder). Save through FilterRuleStore.Save. Uses wizard-select styles.

## Neden
RuleEngine ships but users cannot create rules; explicit user requirement (filters with dozens of criteria).
