# The unsubscribe-on-the-web chip has no Tor-only guard

Kategori: protection | Efor: S | Rank: 3

## Ne
Mail.razor OpenUnsubscribePage calls ExternalLinkService.TryOpen, which hands the URL to the
system browser. List-Unsubscribe URLs embed a per-recipient token by design.
Fix: for a Tor-only account do not offer the http chip - offer the mailto form, which goes out
over the tunnelled SMTP connection - and say why.

## Neden
One click in a Tor-only mailbox delivers "this recipient token, this real IP, this moment" to the
sender over clearnet, from the account whose whole reason for existing is that the pairing never
happens. The reader offers the chip for Tor-only accounts exactly as for any other.
