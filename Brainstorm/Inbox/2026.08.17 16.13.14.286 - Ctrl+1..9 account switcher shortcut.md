# Ctrl+1..9 account switcher shortcut

Kategori: account ergonomics | Efor: S | Rank: 60

## Ne
Extend HandleListKeyDown in Mail.razor.cs (line 544): add `case var d when e.CtrlKey && d.Length == 1 && d[0] is >= '1' and <= '9'` that maps to AccountStore.Accounts[index] and calls the existing SelectAccount(...) helper (which already resets folder/selection), guarding index against Accounts.Count. Add `case "0" when e.CtrlKey` to jump to the unified All Inboxes view (MailUiState.SelectUnifiedInbox()). List the new bindings in the existing ShowShortcutHelp overlay in Mail.razor, and show the ordinal (1., 2., ...) next to each account entry in the sidebar so the mapping is discoverable.

## Neden
j/k/u/s/i keyboard triage is already shipped but switching accounts still requires the mouse; this closes the last mouse dependency in the triage loop with one switch-case addition.
