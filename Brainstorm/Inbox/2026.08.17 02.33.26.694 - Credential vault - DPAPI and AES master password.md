# Credential vault - DPAPI and AES master password

Kategori: protection | Efor: M | Rank: 7

## Ne
CredentialVault in MainProject: stores account passwords encrypted. Mode A: DPAPI (Windows CurrentUser). Mode B: AES-GCM with PBKDF2 master password. Setting picks mode; vault file in UserData. Export-import portable bundle (re-encrypts with user passphrase) for machine migration.

## Neden
User chose both modes plus easy data migration and optional full-data encryption.
