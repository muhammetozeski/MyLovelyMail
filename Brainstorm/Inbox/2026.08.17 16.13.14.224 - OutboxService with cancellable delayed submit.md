# OutboxService with cancellable delayed submit

Kategori: feature | Efor: M | Rank: 60

## Ne
New static class MainProject/Services/Mail/OutboxService.cs. Mail.razor.cs SendActiveDraftAsync (line ~408) stops calling ComposeService.SendAsync directly and instead calls OutboxService.Enqueue(draft), which reads draft.Account's AccountSettings.UndoSendSeconds (inherited from Settings.UndoSendSeconds, Stores/Settings.cs:95), starts Task.Delay with a per-item CancellationTokenSource, then runs the existing ComposeService.SendAsync when the delay elapses. Exposes PendingSend? Current (draft, DateTime dueUtc), event Changed for UI refresh, and Undo() which cancels the CTS and returns the untouched ComposeDraft (ComposeService.SendAsync only deletes the local draft after a successful SMTP submit, so nothing is lost). A value of 0 sends immediately, preserving current behavior. Send failures after the countdown surface through the existing NotificationService toast path instead of the compose pane, since the pane is already closed.

## Neden
Settings.UndoSendSeconds has existed since the settings store was built but nothing consumes it; this is the smallest service that makes it real without touching SmtpSendService or ComposeService internals.
