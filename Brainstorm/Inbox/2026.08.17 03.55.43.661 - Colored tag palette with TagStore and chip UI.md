# Colored tag palette with TagStore and chip UI

Kategori: organization | Efor: M | Rank: 30

## Ne
MailMessageSummary.Tags is already a List<string>, but tags have no identity beyond the string. Add a TagStore (pattern-copy of FilterRuleStore: JSON via AtomicFile under AppPaths) mapping tag name -> hex color chosen from the LovelyBloom pastel set. In Mail.razor.cs render tags as colored chips on list rows and in the reading pane header, with a small tag-picker popover on the selected message (assign/remove, create-new inline with auto-assigned color). Wire a T keyboard shortcut into the existing keyboard-triage handler to open the picker. Clicking a chip runs the existing SearchService tag: query. RuleEngine tag actions and search keep working unchanged since the tag value stays a plain string.

## Neden
Tags exist in the model, RuleEngine can set them, and search can query them, but the user has no way to see, create, or apply them by hand — this turns a data field into a visible organization feature with zero model changes.
