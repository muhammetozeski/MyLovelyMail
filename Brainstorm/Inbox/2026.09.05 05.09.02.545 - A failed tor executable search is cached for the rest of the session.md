# A failed tor executable search is cached for the rest of the session

Kategori: resilience | Efor: S | Rank: 3

## Ne
TorProcess.Find caches the last search keyed by the TorExecutablePath setting, and a null result
satisfies the reuse condition, so Search() never runs again unless that setting changes.
Fix: do not reuse a null result - or reuse it only for a short window, so a newly installed tor is
picked up without a restart.

## Neden
The app starts on a machine with no tor; the user installs the Tor Browser or drops tor.exe into
the app Tor folder - both documented locations - and the settings card keeps saying "None found
yet." until the app is restarted.
