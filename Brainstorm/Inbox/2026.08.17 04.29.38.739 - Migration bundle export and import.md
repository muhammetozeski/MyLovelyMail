# Migration bundle export and import

Kategori: protection | Efor: M | Rank: 3

## Ne
MigrationService in Stores: ExportBundle(path, passphrase) zips UserData (config, accounts, filters, tags, saved searches) plus CredentialVault.ExportPortable into one .lovelybundle file (ZipArchive); ImportBundle(path, passphrase) restores files into UserData and merges the portable vault, then reloads all stores. Settings gets a Data section with Export/Import buttons using paths typed into a CoreInput (no file picker dependency).

## Neden
User explicitly asked for easy machine migration including re-encryptable credentials.
