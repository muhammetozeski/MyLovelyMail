# All-folders search with saved searches

Kategori: search | Efor: M | Rank: 20

## Ne
New static SearchService (MainProject/Services) with Search(accountId, query) that walks MessageStore.GetFolders(accountId) and each folder's GetSummaries, matching query tokens against Subject, FromName, FromAddress, ToAddresses, PreviewText and Tags (case-insensitive, all tokens must match). Support tiny prefix operators parsed in the service: from:, to:, tag:, has:attachment, is:unread — everything maps to fields already on MailMessageSummary. In Mail.razor, when the existing search box is non-empty add an 'Ara: tüm klasörler' toggle that swaps the list source to SearchService results (each row shows its folder name). A star button saves the current query; saved searches persist as a Setting<List<string>> in Settings and render as clickable chips above the folder list, re-running the query on click.

## Neden
Today search only sees the selected folder; the RAM summary index makes cross-folder search essentially free (it is just an in-memory scan). Operators and saved searches turn the existing search box into the app's main navigation tool without any new storage format.
