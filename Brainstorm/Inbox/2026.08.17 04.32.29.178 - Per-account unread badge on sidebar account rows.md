# Per-account unread badge on sidebar account rows

Kategori: account-depth | Efor: S | Rank: 40

## Ne
In the Mail.razor sidebar, render an unread-count pill on each account header row: sum UnreadCount over MessageStore.GetFolders(account.Id) (or only the Inbox-role folder, matching what folder rows already show), tint the pill with the account's ColorHex accent. Subscribe the sidebar to MessageStore.OnFolderChanged (already wired at Mail.razor.cs line 458 for folder counts) so the badge updates live after sync and after read/unread toggles from MessageActions. Hide the pill at zero. MessageStore.RefreshUnreadCount already maintains accurate per-folder counts, so this is pure UI aggregation with no storage change.

## Neden
Collapsed or unselected accounts currently give no signal that mail arrived; the count is already computed per folder, it just is not surfaced at the account level.
